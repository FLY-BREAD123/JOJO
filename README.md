# 적야 인트라넷

조직원 전용 인트라넷. 하얀색 종이 위에 눌러 찍은 왕관이 상징입니다.

## 기능

- **입장**: 로그인 / 가입 신청. 처음 가입한 사람이 **개발자**(모든 권한)가 되고, 그다음부터는 승인을 받아야 들어올 수 있습니다. 개발자가 보스를 임명합니다.
- **본부**: 조직원증(받은 경고 표시), 조직원 수 / 근무 중 / 내 주간 근무 / 조직 자금, 최근 로그, 지금 근무 중 명단(피크 표시), 이번 주 근무 순위
- **출퇴근**: 출근 · 피크 타임 · 퇴근. 피크 타임은 출근 중에 켜고 끄는 구간이고, 퇴근하면 근무 시간과 피크 시간이 같이 기록됩니다
- **전쟁 보고서**
  - 지상전쟁: 상대 조직(작두 · 사쿠라 · 느와르), 땅 번호(5000~6000), 승리/패배, 함께한 조직원
  - 차량전쟁: 상대 조직, 땅 번호(3200~4000), 승리/패배, 함께한 조직원
  - PVP: 지상전 · 카빈 전용. 상대 조직, 누가 걸었는지(적야가 / 상대가), 승리/패배, 함께한 조직원
  - 위쪽에 지상전쟁 · 차량전쟁 · PVP 전적, PVP 신청 횟수, 상대별 전적 표
  - **스크린샷 자동 체크**: 참여자가 보이는 스크린샷을 올리거나 끌어다 놓거나 Ctrl+V로 붙여넣으면, 사진 속 이름을 읽어 함께한 조직원을 자동으로 체크합니다. 플레이어 목록, 디스코드 음성 채널처럼 이름이 줄지어 보이는 화면에서 잘 되고, 게임 화면 속 머리 위 이름표는 놓칠 수 있습니다. 빠진 사람은 눌러서 추가하세요
- **직급표**: 구분(최고위직 · 고위직 · 일반직 · 수습직 · 특수직) 안에 직급(두목, 부두목 …), 직급마다 이름(고유번호). 인원 수는 자동으로 셉니다
  - 편집(개발자 · 보스 · 부보스): 구분/직급 추가 · 이름 바꾸기 · 순서 · 삭제, 직급 아이콘, 사람 추가 · 다른 직급으로 옮기기 · 빼기
  - **디스코드로 복사**: 디스코드에 올리던 글 모양 그대로 복사됩니다
  - **디스코드 글 불러오기**: 디스코드 직급표 글을 붙여넣으면 그대로 채워집니다 (보이지 않는 글자, 빈 칸은 알아서 정리)
  - 직급표 이름이 인트라넷 계정 이름과 같으면 근무 중인지 점으로 보여 줍니다
- **계산기**: 특총(림피드, 암구사 2억), 카빈소총 4,000만, SMG 3,000만, 권총 1,500만, 총알 300발 500만. 수량을 넣으면 합계가 억·만 단위로 나오고, 견적 복사(디스코드/게임 채팅에 붙여넣기)와 판매 금액 입금 기록을 할 수 있습니다
- **조직 자금**: 잔액, 최근 14일 입출금 그래프, 장부
- **로그**: 출퇴근, 전쟁·PVP, 자금, 인사(가입·승진·경고·퇴장)가 모두 남습니다(최근 2만 건 보관). 분류별로 보고, 로그 저장으로 전체를 텍스트 파일로 내려받습니다
- **새 소식 알림**: 다른 사람이 출근하거나 전쟁 결과를 올리는 등 일이 생기면 5초 안에 오른쪽 위에 알림이 뜨고 소리가 납니다. 위쪽 종 버튼으로 소리를 꺼도 알림은 계속 보입니다
- **관리**: 가입 승인·거절, 직급 변경, 경고(사유 필수, 누적, 취소 가능), 퇴장(사유 선택), 비밀번호 초기화, 상대 조직 목록 · 화폐 표기 변경, 백업 받기 / 복원
- **디스코드 알림** (선택): 출근 · 피크 · 퇴근, 지상전쟁·차량전쟁·PVP 결과, 입출금, 가입 신청, 승진·강등, 경고, 퇴장

## 권한

| 직급 | 할 수 있는 것 |
| --- | --- |
| 개발자 | 모든 것 (첫 가입자, 한 명). 보스 임명 가능, 아무도 개발자를 바꾸거나 퇴장시킬 수 없음 |
| 보스, 부보스 | 관리 메뉴: 승인, 인사, 경고, 퇴장 (자기보다 낮은 직급만), 장부 기록 삭제, 직급표 편집 |
| 간부 이상 | 출금 기록, 남의 보고서 지우기, 아랫사람 퇴근 처리 |
| 모두 | 출퇴근 · 피크, 전쟁 보고서 올리기, 직급표 보기 · 복사, 계산기, 입금 기록, 로그 보기·저장, 내 경고 내역 보기 |

## Render 배포

데이터는 Render **Persistent Disk**에 저장합니다. 디스크는 유료 플랜(Starter 월 $7 이상)에서만 붙일 수 있고, 1GB에 월 $0.25입니다.
Render가 디스크를 매일 자동으로 스냅샷해 둡니다(7일 보관).

**이미 만든 웹 서비스에 디스크 붙이기**
1. 서비스 → 왼쪽 **Disk** → **Add Disk**
2. Name `jeokya-data`, Mount Path **`/var/data`**, Size `1` GB → Save
3. Render가 다시 배포합니다. 서버는 `/var/data`에 디스크가 붙어 있으면 알아서 거기에 저장합니다(`DATA_DIR` 설정 불필요)
4. 디스크를 붙이기 전에 만든 계정·기록은 사라집니다. 배포가 끝나면 바로 **가장 먼저 가입**하세요. 첫 가입자가 개발자가 됩니다

**새로 만들 때**: Render → **New → Blueprint** → 저장소 선택. `render.yaml`에 플랜, 지역(싱가포르), 디스크가 다 들어 있습니다.

`https://주소/healthz`에서 `"store":"disk"`가 보이면 디스크에 저장되고 있는 것입니다(`local`이면 디스크가 안 붙은 상태).

환경변수

| 이름 | 내용 |
| --- | --- |
| `DATA_DIR` | (선택) 데이터 폴더. 비우면 Render에서는 `/var/data` 디스크, 그 외에는 앱 안 `data` 폴더 |
| `DISCORD_WEBHOOK_URL` | (선택) 디스코드 채널 웹훅 주소. 넣으면 알림이 갑니다 |
| `DATABASE_URL` | (선택) 디스크 대신 Postgres(예: Neon 무료)에 저장하고 싶을 때. 있으면 이쪽이 우선 |

- 무료 플랜으로 돌리려면 디스크를 붙일 수 없으니 `DATABASE_URL`(Neon 등)을 넣으세요. 없으면 서버가 잠들 때마다 데이터가 지워집니다.
- Postgres를 쓰면 데이터 전체가 압축돼 한 줄로 저장되고(`jeokya_store`), 서버가 켜질 때마다 `jeokya_backup`에 한 벌씩 남습니다(최근 14개). DB에 닿지 않으면 빈 데이터로 시작하지 않고 몇 번 다시 시도한 뒤 꺼집니다.
- `/healthz`에서 저장소 종류(`store`)와 저장 상태(`saving`)를 볼 수 있습니다.

## 구조

```
server.js            Express 서버, 저장 예약, 디스코드 웹훅
lib/core.js          모든 규칙과 API (서버와 미리보기가 같이 씀)
lib/store.js         저장소: Postgres(DATABASE_URL) 또는 파일
render.yaml          Render Blueprint 설정
public/index.html    화면 전체 (한 파일)
scripts/test-api.js  통합 테스트: npm test
scripts/build-demo.js  서버 없이 도는 미리보기 한 장 만들기
scripts/seed-data.js   미리보기용 예시 데이터
```

- 데이터는 `DATABASE_URL`이 있으면 Postgres, 없으면 `data/data.json` 하나에 저장됩니다.
- 비밀번호는 scrypt로 해시, 로그인은 토큰 방식(14일 유지), 같은 아이디로 연속 8번 틀리면 5분 잠금.
- 날짜·주간 계산은 한국 시간 기준 (이번 주 = 월요일 0시부터).
